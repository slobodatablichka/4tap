# START

## Назначение

Этот репозиторий — каноническая интерактивная техническая документация 4Tap / KnockUI.

## Правила

1. Факты и параметры проекта хранятся в `data/*.json`.
2. `index.html`, `styles.css`, `app.js` отвечают за представление, но не должны становиться вторым источником технических данных.
3. Каждая смысловая ячейка имеет уникальный `id`, краткое пояснение и полное описание.
4. Связи между ячейками задаются в `data/relations.json`.
5. Двухсимвольные назначения задаются только в `data/gestures.json`.
6. Непроверенные технические предположения помечаются статусом `needs-validation`.
7. После существенного изменения архитектуры обновляется документация тем же коммитом, что и связанные данные.

## Первая карта

Начальный поток:
Quad Tap → Local Canvas → Gesture 1 → Gesture 2 → Recognizer → Command → System/User registry → Action Dispatcher → App/Deep Link.
