# 4Tap / KnockUI

Интерактивная техническая документация проекта 4Tap / KnockUI.

Сайт: https://slobodatablichka.github.io/4tap/

## Принцип

Репозиторий хранит одновременно:
- канонические данные документации;
- визуальную карту проекта;
- связи между архитектурными элементами;
- реестр двухсимвольных комбинаций.

Содержательная часть находится в `data/`. HTML/CSS/JS отвечают за представление и интерактивность.

## Структура

- `index.html` — одностраничная оболочка.
- `styles.css` — визуальная система.
- `app.js` — рендеринг, фильтры, поиск, связи и матрица комбинаций.
- `data/sections.json` — разделы карты.
- `data/cells.json` — технические положения и интерактивные ячейки.
- `data/relations.json` — связи между ячейками.
- `data/gestures.json` — назначенные двухсимвольные комбинации.
- `START.md` — правила ведения.
- `CURRENT-STATE.md` — текущее состояние документации.

## Охват

Карта включает:
- общую модель KnockUI;
- Android;
- iOS;
- WeChat;
- WhatsApp;
- B2C и B2B;
- Design Canon и 4Tap Graffiti Profile;
- пользовательскую настройку и каталоги интеграций;
- региональную стратегию;
- дистрибуцию, монетизацию и продвижение;
- roadmap;
- методологию разработки.

Технические положения, которые ещё не подтверждены прототипом или официальными ограничениями платформы, помечаются `needs-validation`.
